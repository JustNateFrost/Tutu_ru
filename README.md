# Проект Tutu_ru включает в себя: 6 api-автотестов, 5 ui-автотестов.
# Подключенные зависимости и библиотеки: selenium, requests, pytest, allure.
# Для запуска только api-автотестов: pytest test_api.py
# Для запуска только ui-автотестов: pytest test_ui.py
# Для запуска всех автотестов: pytest -v
# Для запуска тестов для формирования отчета: python -m pytest --alluredir allure-results
# Для просмотра сформированного отчета: allure serve allure-results
